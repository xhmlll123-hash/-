# Pickora 文案与内容规范 (CONTENT COPY)

本文档整理并规范了 Pickora 微信小程序当前用户可见的核心文案和品牌词汇。所有后续的文案修改和功能扩展，均需遵循此文档以保持品牌一致性。

## 1. 核心品牌词汇（必须保留）

*   **极速起局**：代表无需输入具体选项的快速二选一流程。
*   **常用签牌**：指代日常高频使用的模板组合（如吃什么、去哪玩等）。
*   **推荐权重列表**：在结果页中展示各选项得分排名的列表。
*   **权重**：用于衡量选项推荐程度的分数/级别。
*   **六象池**：用于决定最终结果的六个象征性符号集合。
*   **首推**：系统计算后得出的第一推荐结果。
*   **落象**：选项最终匹配到的“象”及寓意。

## 2. 模块文案规范

### 2.1 首页
*   **主标题**：`纠结时，起一局`
*   **副标题**：`写下几个选项，Pickora 帮你轻松挑一个。`
*   **极速起局入口**：必须明确显示为“极速起局”，其内部流转不再暴露占位符 1/2。

### 2.2 极速起局流程
*   **结果展示**：必须且仅能使用 **“第一个念头”** 与 **“第二个念头”** 作为展示文本，严禁显示数字占位符（“1”或“2”）。
*   **去掉首推重来**：在极速起局中，点击该操作将直接在“第一个念头”与“第二个念头”之间切换结果，不进入常规编辑流程。

### 2.3 常用签牌与编辑页
*   **顶部标题**：`帮我选一下`
*   **常规模板命名**：例如“吃什么”、“去哪玩”、“去哪吃”、“买哪个”、“先做什么”及“自定义”。
*   **候选项输入**：`输入候选项，点加入后开始选择。`

### 2.4 已去掉状态（编辑页）
*   **卡片标题**：`已去掉 N 个`。
*   **恢复操作**：统一使用 `恢复`，作为小型操作按钮置于右侧，不抢占主视觉。

### 2.5 结果页
*   **结果页标题**：`首推结果`（稳定展示状态） / `正在起象…`（加载过渡状态，注意目前已跳过高频闪烁动画）。
*   **支撑信息标题**：`本轮选择池`、`六象池`、`推荐权重列表`。
*   **提示语气**：保持轻量、禅意，不做强烈的错误警告。

### 2.6 接受结果封面
*   **确认文案**：`已定`。
*   **引导/寄语（随机短句）**：使用诸如“相信自己的选择。”、“顺其自然，自有答案。”、“此去经年，皆是序章。”等充满东方哲学与心理暗示的随机寄语文案。
*   **再来操作**：`再来一局`。

### 2.7 选项库
*   **页面标题**：`个人选项库`。
*   **说明文字**：`误存的选项可以删掉。`

### 2.8 错误与空状态提示
*   **无速选项提示**：`没有可速选的选项了，可以恢复已排除项或新增选项。`（使用轻量米红/米黄底色，避免刺眼的强警告）。
*   **少于一个选项时提示**：`先加至少一个候选项。` / `先填两个不同选项。`
*   **选项库空状态**：`还没有历史选项。完成一次速选后会自动保存。`

### 2.9 娱乐边界提示（必须保留）
*   **底部免责声明**：`仅作娱乐化选择辅助，不用于医疗、法律、投资等重要决策。`
*   **引用彩蛋（Reflection Quote）**：
    *   默认使用原创短句，不直接引用影视剧、歌词、书籍中的长句。
    *   保留 3-5 条原创候选短句，例如：
        *   `答案落下之前，心里其实已有偏向。`
        *   `签只是借口，选择仍在你手里。`
        *   `不必求准，只求此刻能往前一步。`
